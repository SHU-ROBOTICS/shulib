## What Phase E leaves the estimator able and unable to do

Stated plainly because F1/F2 and Phase R will both be read against it.

**Can:** bound position drift with the GPS strip in view; correct absolute heading from AprilTags;
arbitrate two disagreeing correctors by their stated σ (EKF tier); recover from a displacement the
fixed gate refuses; report its own uncertainty; reconstruct every gating decision from a blackbox

**Cannot, and this matters:** the **EKF is not the default** — measured over 8 seeded runs it lost
7 of 8 to the complementary filter, because simulated dead-reckoning is already sub-inch and the
modelled GPS is noisier than the drift it corrects. Nothing here has met real hardware. **91
registered assumptions, none settled.** Chapter 14 is the honest list; keep it that way.

## Process notes worth carrying over

The chunk loop in `RESUMING.md` works and should not be changed. These are additions this session
earned:

**Write an independent oracle for anything geometric or numeric.** A test that shares a conversion,
a camera model or a motion model with the code under test **cancels its own sign errors**. This has
now bitten **C1, C3, C4, E2, E3** — five times. Reviewer-written oracles at E2 (frame + lever arm),
E3 (PnP projection) and E4 (Cholesky) each found or confirmed something real; E2's found a
pre-existing defect where a test imported the very constant it was pinning.

**Prose goes stale in ways no gate catches.** The four build-time doc gates (undocumented member,
stale generated reference, drifted example, internal link) are solid and worth trusting. They have
no opinion about whether a *sentence* is still true. Four separate stale-prose defects were found by
reading this session — a chapter claiming 57 assumptions when there were 67, a README claiming 659
tests beside a claim of 867, an API chapter describing an exception that had been deleted, a feature
shipped entirely undocumented. **Budget reading time, not just gate time.**

**Under-claim harder when a result flatters.** The three best moments this session were all
retractions: E2 refusing a scenario that would have passed 8/8 as scenario-shopping, E3 striking a
headline finding after discovering it had inferred a sign, and E4 reporting that the EKF lost the
comparison its own DoD demanded. **A chunk that reports only wins has not looked hard enough.**

**Assertion counts flatter.** 48 new cases produced 430,252 new assertions at E4. The count measures
seeds swept. Mutation results are the measure that means something.

## Things that are true and easy to get wrong

- **`main` is a squash of `release/v2` with `docs/internal/` dropped.** The release flow is in the
  git history (`git log --first-parent main`). The site publishes from `main`, so **E1–E4 are not on
  docs.shurobotics.com yet** — they land at the next release squash.
- **HTTPS on the docs site is still pending** GitHub issuing a certificate; the DNS is correct and
  the site serves over HTTP. Enable "Enforce HTTPS" once the cert appears.
- **A V5 brain boots this code** (2026-08-12, evidence in `evidence/`), and **drives nothing** —
  the `hal/pros` adapters are R1. Do not let that fact drift upward into "it works on a robot".
- **F6 (`Chassis`) and F10 (`Routine`) are frozen** and compile-pinned. Changing a signature fails
  the build naming the register row. That is intentional; if F1 needs a facade change, it is a
  breaking change with a migration note, not an edit.

## If a robot is available

An old practice bot unblocks roughly 20–25 register entries — the **V5-platform** ones (IMU drift
and calibration window, GPS noise and latency, encoder refresh, brownout threshold, real loop rate).
Those are not geometry-specific, so a practice chassis measures them as well as the competition one
will. **Never carry gains across chassis**, and record anything measured on a practice bot with that
provenance rather than as "measured".

Doing this does not break the build order: R1–R3 are *authored throughout and run on arrival*, and
arrival has already happened for platform-level work.
